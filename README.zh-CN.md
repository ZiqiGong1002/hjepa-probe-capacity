# H-JEPA 中的探针容量与选择性抽象

[English](README.md) · [上游原始 README](UPSTREAM_README.md)

本仓库在 [H-JEPA](https://arxiv.org/abs/2610.06805) 官方实现的基础上，于 FourRoom 环境中开展探针研究：(i) 复现论文的逐层探针结果；(ii) 检验论文「选择性抽象」的结论是否依赖于所用探针的容量。

| | |
|---|---|
| 上游 | [kevinghst/H-JEPA](https://github.com/kevinghst/H-JEPA)，提交 `97054ec`，MIT 许可证 |
| Checkpoint | Hugging Face 上的官方 FourRoom checkpoint（2、3、4 层），已校验 SHA-256 |
| 改动 | `h_jepa/` 下的 3 个提交（`git log 97054ec..HEAD -- h_jepa`），以及 `probing/` 下的实验代码与结果 |
| 不包含 | 数据集与 checkpoint，下载方法见 [`UPSTREAM_README.md`](UPSTREAM_README.md) |

## 主要结论

1. **Fig. 4 复现。** 4 层模型（3 个模型种子）各层干扰物位置 NMSE 为 0.053 / 0.167 / 0.340 / 0.553，与论文报告值（≈0.06 / 0.19 / 0.37 / 0.58）一致。
2. **不同 MLP 探针宽度下的逐层趋势。** 3 层与 4 层模型在宽度 128、512、2048 的 MLP 探针下，干扰物位置 NMSE 均随层级单调上升。3 层模型在宽度 128 以上基本饱和（第 3 层 NMSE 变化不超过 0.02）；4 层模型的高层数值随宽度略有下降（宽度 128 到 2048，L3 下降 0.07、L4 下降 0.06），幅度与模型种子间波动相当，且该比较仅基于单个模型种子。
3. **对探针类型敏感。** 线性探针的 NMSE 显著更高（0.446 / 0.672 / 0.903）。因此，表征看起来「丢弃」了多少信息，很大程度上取决于探针是线性还是非线性。
4. **随机编码器基准。** 同架构的未训练编码器在各层的干扰物位置 NMSE 为 0.77–0.80，agent 位置 NMSE 为 0.90–0.92，表明可解码的信息来自训练。
5. **未解决的差异。** 2 层模型（Fig. 12）第 2 层结果与论文一致，第 1 层干扰物位置 NMSE 不一致（0.156 vs ≈0.01）。

## 背景与研究问题

H-JEPA 通过在冻结的潜在表征上训练探针，评估分层结构中各层编码了哪些信息。论文中，较高层保留 agent 位置，同时逐层丢弃干扰物信息，并将此解释为选择性抽象。论文中所有探针结果均使用同一种探针结构（单隐藏层、512 单元的 MLP）。

探针衡量的是该探针能够*解码*的信息，而非表征中*存在*的信息。弱探针无法恢复的信息仍可能被编码；足够强的探针也可能恢复下游模型并不使用的信息。因此本研究的问题是：

> 「较高层丢弃干扰物信息」这一结论，在不同容量的探针下是否依然成立？

## 方法

**模型。** 官方 H-JEPA FourRoom checkpoint（2、3、4 层），编码器参数全部冻结。

**探针。** 全程使用官方探针配置（AdamW，学习率 1e-3，weight decay 1e-4，batch size 128，60 epoch，探针种子 42）。探针为单隐藏层结构，含 LayerNorm 与 GELU，仅改变隐藏层宽度：

| 探针 | 隐藏层宽度 | 参数量 |
|---|---|---|
| 线性 | 0 | 386 |
| MLP | 128 | 25k |
| MLP（官方） | 512 | 101k |
| MLP | 2048 | 403k |

**预测目标。** agent 位置（`xy`）、干扰物位置（`distractor0_xy`）、agent 到最近干扰物的测地距离（`min_distractor_dist`）。

**指标。** 评测集上的归一化均方误差（NMSE）。NMSE = 1 相当于预测目标均值，数值越低越好。

**对照。**
- *仅位置对照*：用官方 MLP-512 探针，以真实 agent 位置和关闭的门的编号代替学到的特征作为输入，衡量各目标中能由 agent 位置单独预测的部分。
- *随机编码器基准*：用官方构造函数实例化 3 层架构但不加载训练权重，以相同方式进行探针评估。

**实现。** 对 `h_jepa/` 的改动如下：

| 提交 | 说明 |
|---|---|
| Make probe hidden_dim configurable | 新增 `probe_hidden_dim`（0 = 线性），默认值 512 保持原代码路径 |
| Add cached-embedding probing runner | `main_probing_cached.py`：冻结编码器仅计算一次并缓存特征，以相同的探针头、随机数序列和指标训练探针 |
| Cached probing: optional random_init baseline | `+random_init=true`：实例化同架构但不加载训练权重 |

缓存版已与官方流程对照验证：在 3 层模型（seed 42，MLP-512 探针）上，18 个 NMSE 数值完全一致（最大绝对差为 0；`probing/scripts/compare_metrics.py`）。

**预注册。** 容量扫描的假设在获得任何完整结果之前记录于 [`probing/PREREG.md`](probing/PREREG.md)。

## 结果

### Fig. 4 复现（4 层模型，干扰物位置）

| | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| 论文（图中读数） | ≈0.06 ± 0.02 | ≈0.19 ± 0.05 | ≈0.37 ± 0.08 | ≈0.58 ± 0.07 |
| 本研究（3 个模型种子，均值 ± 标准误） | 0.053 ± 0.020 | 0.167 ± 0.050 | 0.340 ± 0.073 | 0.553 ± 0.072 |

各层 agent 位置 NMSE 均约为 1e-4，与论文一致。

### Fig. 12 复现（2 层模型，seed 42）

| | Agent L1 | Agent L2 | 干扰物 L1 | 干扰物 L2 |
|---|---|---|---|---|
| 论文 | ≈0 | ≈0 | ≈0.01 | ≈0.33 ± 0.01 |
| 本研究 | 4e-5 | 7e-5 | **0.156** | 0.341 |

第 2 层与论文一致，第 1 层干扰物结果不一致。Fig. 12 图注说明各环境使用的探针头不同，该图所用探针可能与公开配置不同。原因尚未确定。

### 探针容量（3 层模型，seed 42）

论文未报告 3 层模型的探针结果。

| 探针 | 干扰物位置 L1 / L2 / L3 | 测地距离 L1 / L2 / L3 | Agent 位置 |
|---|---|---|---|
| 线性 | 0.446 / 0.672 / 0.903 | 0.816 / 0.854 / 0.863 | 0.002–0.007 |
| MLP-128 | 0.117 / 0.313 / 0.507 | 0.326 / 0.506 / 0.631 | ≈1e-4 |
| MLP-512（官方） | 0.105 / 0.275 / 0.492 | 0.307 / 0.489 / 0.619 | ≈1e-4 |
| MLP-2048 | 0.098 / 0.257 / 0.487 | 0.301 / 0.467 / 0.615 | ≈1e-4 |
| 仅位置对照（MLP-512） | 0.981 | 0.873 | — |

- **容量。** 从线性探针到 MLP-128，第 3 层干扰物 NMSE 下降 0.40。宽度超过 128 后，第 3 层 NMSE 变化不超过 0.02，小于 Fig. 4 中模型种子间的波动（≈0.07）。
- **层级顺序。** 所有探针（包括线性探针）下，NMSE 均从 L1 到 L3 递增。
- **过拟合。** MLP-2048 的训练–评测差距（≈0.03）与 MLP-512 相同，未见额外过拟合。
- **对照。** 学到的表征在测地距离上的 NMSE 为 0.30–0.63，明显低于仅位置对照（0.873），表明表征编码了 agent 位置之外的干扰物信息。

### 探针容量（4 层模型，seed 42）

| 探针 | 干扰物位置 L1 / L2 / L3 / L4 | L4 训练–评测差距 |
|---|---|---|
| MLP-128 | 0.051 / 0.188 / 0.411 / 0.643 | 0.027 |
| MLP-512（官方） | 0.046 / 0.168 / 0.377 / 0.617 | 0.049 |
| MLP-2048 | 0.043 / 0.152 / 0.339 / 0.579 | 0.042 |

- **层级顺序。** 所有宽度下 NMSE 均从 L1 到 L4 递增。
- **容量。** 从 MLP-128 到 MLP-2048，L3 下降 0.07、L4 下降 0.06，而 3 层模型的变化不超过 0.02。该幅度与 Fig. 4 中模型种子间的波动（≈0.07）相当；由于仅有单个模型种子，无法与种子波动区分。
- **过拟合。** MLP-2048 的训练–评测差距不大于 MLP-512，未见额外过拟合。

### 随机编码器基准（3 层架构，MLP-512 探针）

| 评测 NMSE，L1 / L2 / L3 | Agent 位置 | 干扰物位置 | 测地距离 |
|---|---|---|---|
| 未训练编码器 | 0.904 / 0.919 / 0.906 | 0.773 / 0.777 / 0.797 | 0.993 / 0.995 / 0.996 |
| 训练后的 H-JEPA | 5e-5 / 7e-5 / 7e-5 | 0.105 / 0.275 / 0.492 | 0.307 / 0.489 / 0.619 |

未训练特征信息量很低，且与层级无关，说明层的堆叠本身不会丢弃信息。训练后，agent 位置在各层均可解码，干扰物信息在 L1 基本可解码。在较高层，干扰物 NMSE 接近但仍低于未训练基准，即信息的减少是部分的而非完全的。

### 预注册假设的检验结果

| | 假设 | 结果 |
|---|---|---|
| H1 | Agent 位置在所有容量下可解码；线性探针明显更差；MLP 探针饱和 | 支持 |
| H2 | 干扰物位置在所有容量下 NMSE ≈ 1.0 | 不支持（MLP 探针为 0.10–0.49） |
| H3 | 测地距离主要由 agent 位置解释（表征 ≈ 对照） | 不支持（0.30–0.62 vs 0.873） |
| H4 | 若 MLP-2048 仅改善训练集而不改善评测集 NMSE，则视为不可解码 | 未触发 |

表征中的干扰物信息多于 H2、H3 的预期。

## 讨论

在 MLP 探针范围内，论文的定性结论成立：在 3 层与 4 层模型中，所有测试宽度下干扰物信息都在较高层逐渐变得难以解码。4 层模型高层的绝对数值随探针宽度略有下降，说明这些层上可恢复的信息量对探针容量有一定敏感性。探针类型的影响则大得多。线性探针会得出连第一层也丢弃了大部分干扰物信息的结论，而非线性探针表明这些信息在很大程度上仍可恢复。因此，关于某一层「丢弃」了什么信息的表述，应注明所用的探针。

## 局限

- 所有探针仅使用一个探针种子（42），与官方配置一致。
- 容量扫描（3 层与 4 层）与 Fig. 12 复现仅使用一个模型种子（42）。
- Fig. 12 第 1 层的差异尚未解决。
- FourRoom 中不存在快速变化的本体感知变量。「较高层丢弃腿姿等快变量、保留位置」这一更广泛的结论，需要在具身环境（如 H-JEPA 同样提供的 Ant）中验证。

## 复现

```bash
# 环境与数据：按 UPSTREAM_README.md（uv，Python 3.11）
export HJEPA_HOME=/path/to/data

# 公开的 checkpoint 不含探针脚本所需的训练配置，需为每个 checkpoint 重建，例如
python probing/scripts/make_train_config.py h_jepa/config/train fourroom_hjepa_l3 42 \
    $HJEPA_HOME/ckpts/fourroom/fourroom_hjepa_l3/seed42/config.yaml

# 单次运行：<模型> <模型种子> <探针隐藏层宽度>
bash probing/scripts/run_probe.sh l3 42 512

# 上文报告的全部运行，依次执行
bash probing/scripts/sweep.sh

# 仅位置对照
python probing/scripts/xy_only_control.py
```

`probing/results/` 包含上文每次运行的 `metrics.yaml`。3 层模型的线性探针结果由官方流程得到（`probing/results/C_h0`），其余容量结果由缓存版得到。

**环境。** NVIDIA RTX 4080 Laptop GPU（12GB），WSL2；Python 3.11；PyTorch 2.7.1（CUDA 12.6 版本，因上游指定的 CUDA 12.8 源无法访问）。该系统上并发运行多个 CUDA 进程会导致驱动故障，因此所有运行均串行执行；`run_probe.sh` 对失败的运行最多重试三次。
